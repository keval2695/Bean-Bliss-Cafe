# Bean Bliss

A responsive café and restaurant website built using HTML, CSS, and JavaScript.

## Features

- Responsive layout for mobile and desktop
- Interactive navigation and hero slider
- Menu and featured-item sections
- Reservation form interface
- Café contact and location details

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Ionicons

## Run Locally

Clone or download this project and open `index.html` in a browser.
